# Grammar WASM Provenance

Elm, YAML, Markdown, SQL, Dockerfile, Make, and Git-ignore WASM files are from `tree-sitter-wasm` 2.0.2 (MIT-licensed package).

The QL grammar is from `tree-sitter-ql` 1.0.0 (MIT) and was regenerated with `tree-sitter-cli` 0.27.0 to use the current Tree-sitter language ABI.
